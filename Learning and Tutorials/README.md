# 📚 Master Learning & Tutorial Portal

> **Hostel Management System - Project-Based Learning (PBL)**  
> **Institution:** Sharda University Agra  
> **Methodology:** Equalized 4-Member Parallel Learning & Execution Framework (25% Each)

---

## 🎯 Purpose of this Learning Portal

This portal is designed to ensure that **every member of the project group understands the technology stack thoroughly**, learns in parallel with project development, and is 100% prepared to answer questions during college evaluations, teacher reviews, and technical vivas.

Rather than having one person do all the technical work while others only watch, this framework gives **equal 25% technical ownership** to each student:
- You will find curated free resources (official documentation, freeCodeCamp, YouTube video courses in English & Hindi, interactive sandboxes).
- Each member has a **phase-by-phase learning syllabus** mapped directly to the project roadmap.
- Each member has a **Core Concepts** breakdown explaining how their code works under the hood.
- Each member has a dedicated **Viva & Oral Evaluation Prep Guide** with top 20 questions and answers.

## 📖 How to Use Your Learning Folder

Navigate to your assigned subfolder:
1. Start with `01_learning_syllabus_and_roadmap.md` to see what topics you need to master.
2. Read `02_core_concepts_to_understand.md` for simplified explanations and architectural diagrams.
3. Watch the video courses and read the official docs linked in `03_free_resources_and_tutorials.md`.
4. Test yourself using `04_viva_and_interview_prep.md` before meeting your college teacher or external examiner!
