## 🌐 Multi-College Dynamic ID Auto-Detection Engine

Unlike standard single-hostel apps, this platform features an **Automated Institutional Identification & Routing Engine** (`client/src/services/multiCollegeData.js`). 

When any resident, warden, or director inputs their Institutional ID or University Email into the Single Sign-On console, the platform dynamically parses the prefix pattern and credentials to detect their institution, campus wing, room, and security permissions before routing them to their dedicated, branded portal:

## 🏛️ Government & Institutional UI Design (GIGW Compliance)

The user interface follows the **Guidelines for Indian Government Websites (GIGW)** and institutional design standards:

- **Accessibility Strip (`AccessibilityToolbar`):**
  - **Text Resizing:** Dynamic Root `rem` scaling: `A-` (0.875rem), `A` (1rem Normal), `A+` (1.125rem Large) for vision accessibility.
  - **High-Contrast Mode:** 1-click toggling of high-contrast monochrome themes with enhanced borders (`border-yellow-400 bg-black text-white`).
  - **Live IST Digital Clock:** Synchronized Asian/Kolkata timezone digital clock ticking live in real-time.
  - **Toll-Free National Helpline:** Instant-dial direct emergency campus dispatch (`1800-180-2026`).
- **Dynamic University Emblem & Accreditation Badges:** Verified NAAC A+ accreditation emblems, UGC/AICTE statutory clearance ribbons, and live campus notification tickers.
- **Micro-Animations & Visual Hierarchy:** Subdued government styling, professional data tables, responsive stat cards, and clean typography.

## 🛡️ Clear Role Separation: Admin vs Warden vs Student

The system strictly divides administrative responsibilities to mirror actual campus operations:

### 1. 👨‍💼 University Directorate / Executive Admin (`/admin`)
Designed for University Deans, Hostel Directors, and Chief Registrars.
- **Macro Campus Analytics Suite (`AnalyticsCharts.jsx`):**
  - *Hostel Wing Occupancy:* SVG bar charts comparing Boys Block B, Girls Block A, and PG Wings.
  - *2026–27 Term Fee Revenue:* Interactive SVG revenue curves showing monthly collections vs overdue arrears.
  - *Maintenance Breakdown:* Category distribution visualization (HVAC, Plumbing, Electrical, Wi-Fi).
  - *Executive KPIs:* Total resident capacity, live occupancy rate, active hostel wings, pending grievances.
- **1-Click Data Pipeline & CSV Exporters:**
  - Export Resident Scholars Directory to CSV.
  - Export Monthly Curfew & Attendance Roll to CSV.
  - Export Term Fee Collections & Payment Ledgers to CSV.
  - Export Facility Maintenance Ticket Logs to CSV.
- **Campus Governance:** Multi-hostel capacity configuration, institutional notices, fee structures, and directorate announcements.

### 2. 🛡️ Warden Ground Operations Desk (`/warden`)
Designed for Floor Wardens, Wing In-Charges, and Security Supervisors.
- **09:30 PM Night Biometric Roll Call:**
  - Real-time resident attendance roster with 1-click individual marking (`Present`, `Leave`, `Late Entry`, `Absent`).
  - "Mark All In-House Present" batch action for rapid evening roll calls.
  - Real-time wing headcount percentage meter.
- **Outstation Gate Pass Triage & Official Email Dispatch:**
  - Review weekend outstation gate pass requests with parental contact verification.
  - Approval generates a verifiable gate pass token (`PASS-SUA-2026-XXX`).
  - **Official University Email Dispatch Modal (`EmailDispatchModal.jsx`):** Generates an official university-formatted HTML departure slip sent via simulated SMTP to the student, parent CC, and security gatehouse.
- **Maintenance Dispatch Console:** Assign HVAC, electrical, and plumbing tickets to physical campus technicians (`Rajesh HVAC Tech`, `Campus IT Desk`, etc.).
- **Campus Gatehouse Visitor Logs:** Track visiting parents/guardians, arrival times, and campus clearance exit statuses.
- **Hostel Wing Bulletin & Mess Monitoring:** Broadcast wing-level alerts and monitor dining ratings.

### 3. 👨‍🎓 Resident Scholar Portal (`/student`)
Designed for hostel residents for complete self-service.
- **Academic Profile & Resident Identity:** Room number, bed assignment, allocated wing, chief warden contact, and emergency desk.
- **Profile Photo & Avatar Customizer (`ProfileModal.jsx`):** 
  - Upload custom profile photo or choose from 6 institutional scholar avatars.
  - Update emergency contact numbers, medical alerts, and blood group.
  - Changes instantly persist to local storage and application state.
- **Verifiable Dynamic SVG QR Outstation Gate Pass (`DigitalGatePassModal.jsx`):**
  - Approved passes generate an encrypted SVG QR Code readable by campus security guards.
  - Complete with digital seal, validity timestamps, and resident credentials.
- **Digital Fee Collection & Razorpay Payment Simulator (`PaymentModal.jsx`):**
  - Instant fee payment checkout with card, UPI, and net banking options.
  - Automatic generation of an official printable A4 PDF Fee Receipt with QR validation stamp.
- **Mess Menu Timetable & Dining Rating (`MessFeedbackModal.jsx`):**
  - Interactive daily mess timetable (Breakfast, Lunch, Snacks, Dinner).
  - 5-star rating console with meal quality feedback dispatched directly to the warden desk.
- **Room Maintenance Grievance Ticketing:** Submit repair requests with category, priority, and live status tracking (`Pending Review`, `In Progress`, `Resolved`).

## ⚡ Quick Start & Local Execution

### Prerequisites
- **Node.js** (v18.x or v20.x recommended)
- **npm** (v9.x or v10.x)
- *Optional:* MongoDB instance (app runs in zero-setup high-fidelity mock mode automatically if MongoDB is offline)

### 1. Installation
Clone the repository and install dependencies:
```powershell
# Install client dependencies
cd client
npm install

# Install server dependencies
cd ../server
npm install
```

### 2. Launch Development Servers
Open two terminal windows:

**Terminal 1 (Backend Server):**
```powershell
cd server
npm start
# Server starts on http://localhost:5000 with Socket.IO and Helmet security
```

**Terminal 2 (Frontend Client):**
```powershell
cd client
npm run dev
# Vite server starts on http://localhost:5173
```

### 3. Verification & Production Build
To verify production bundle compilation:
```powershell
cd client
npm run build
# Compiles 1600+ modules with zero errors into client/dist
```
