2. MONGODB ATLAS CLOUD DATABASE SETUP (FREE M0 TIER)
--------------------------------------------------------------------------------
MongoDB Atlas is the cloud database where all your university data (students, 
rooms, attendance, leaves, complaints) will be stored securely online.

Step 2.1: Create Free Account
- Go to: https://www.mongodb.com/cloud/atlas/register
- Click "Sign up with Google" or enter your email and choose a password.

Step 2.2: Create Free Database Cluster
- After logging in, you will see a screen asking "Deploy a cloud database".
- Select the tier: "M0 Free" (Shared, 512 MB Storage, $0/month).
- Provider: Select "AWS".
- Region: Choose the region nearest to you (e.g., "ap-south-1 Mumbai" or "eu-central-1").
- Cluster Name: Keep it as `Cluster0` (or name it `sharda-hostel-cluster`).
- Click the green button: "Create Deployment".

Step 2.3: Create Database User Credentials (IMPORTANT!)
- A security pop-up ("Quick Start") will appear.
- Username: Type `ayush_admin` (or any username you prefer).
- Password: Click "Autogenerate Secure Password" OR create your own password 
   (Example: use a strong unique password stored only in your password manager.)
⚠️ NOTE: WRITE DOWN OR COPY THIS USERNAME AND PASSWORD RIGHT NOW! 
You will need them in the connection string.
- Click "Create Database User".

Step 2.4: Whitelist IP Address (Allow Connection From Anywhere)
- Scroll down to "Where would you like to connect from?".
- Click "IP Access List".
- Enter IP Address: `0.0.0.0/0`
- Description: `Allow all connections (Localhost & Render)`
- Click "Add Entry".
(This allows your laptop at home, college Wi-Fi, and your hosted cloud server 
to reach the database without being blocked).

Step 2.5: Get the MongoDB Connection String URI
- Click "Choose a connection method" (or click "Connect" on the cluster card).
- Select: "Drivers".
- Driver: Choose "Node.js", Version: "5.5 or later".
- You will see a connection string like this:
  mongodb+srv://ayush_admin:<password>@cluster0.abc12.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0

Step 2.6: Prepare Your Connection String
1. Replace `<password>` with the actual password you created in Step 2.3 (remove the `< >` brackets).
2. Right before the `?retryWrites=true`, add the database name: `hostel_management_db`.
Your final URI will look like:
mongodb+srv://ayush_admin:YOUR_PASSWORD@cluster0.abc12.mongodb.net/hostel_management_db?retryWrites=true&w=majority

Copy this prepared URI. You will paste it into `server/.env` under `MONGO_URI`.

10. BEGINNER TROUBLESHOOTING & FAQ
--------------------------------------------------------------------------------

Q1: "MongooseServerSelectionError: connect ECONNREFUSED"
-> Cause: MongoDB is not reachable.
-> Fix: In MongoDB Atlas, go to "Network Access" and ensure `0.0.0.0/0` is added to 
   the IP whitelist. Also check that your database username and password in `server/.env` 
   do not have typos.

Q2: "Port 5000 is already in use"
-> Fix: Change `PORT=5001` in `server/.env` and update `VITE_API_URL=http://localhost:5001/api` 
   in `client/.env`.

Q3: "CORS error in browser console"
-> Fix: Ensure `server/.env` has `CLIENT_URL=http://localhost:5173`. If using a 
   different frontend port, update `CLIENT_URL` to match it.

Q4: "Can I run the project without MongoDB Atlas internet connection?"
-> Yes! If you install MongoDB Community Server locally on your laptop, you can 
   use `MONGO_URI=mongodb://localhost:27017/hostel_management_db` in `server/.env`.
   The frontend also has complete mock fallback data built-in!
