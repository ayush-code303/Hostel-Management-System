================================================================================
          HOSTEL MANAGEMENT SYSTEM - MASTER EXECUTION PLAN (plan.txt)
================================================================================
Project Type: College Project / Project-Based Learning (PBL) - Sharda University Agra
Group Size: 4 Members (Ayush, Anushka, Bhoomi, Palak)
Methodology: Educational Bottom-Up Approach with Equal 25% Parallel Engineering
Architectural Stack: React.js (Vite) + Node.js + Express.js + MongoDB (Mongoose)
Supporting Services: Cloudinary, Razorpay, Socket.IO, Postman QA
Deployment: Vercel (Frontend), Render (Backend), MongoDB Atlas (Database)
Course Timeline: 12-Week Weekly Milestone & Reporting Structure

--------------------------------------------------------------------------------
1. PROJECT PHILOSOPHY & EQUALIZED 4-MEMBER OWNERSHIP (25% EACH)
--------------------------------------------------------------------------------
Every member has a distinct, fully equalized 25% engineering responsibility across all 12 weeks:

1. AYUSH (25% - Lead Architect & Core Backend Engineer):
   - Backend architecture, MongoDB schemas, database seeder, security configuration.
   - Core REST APIs: Authentication (JWT/RBAC), Student profiles, Hostel & Room management, Fees.
   - Payment gateway integration (Razorpay), backup automation, server health & production deployment.

2. ANUSHKA UPADHYAY (25% - Frontend Lead & Student Experience Engineer):
   - Frontend architecture, Vite + React setup, Tailwind CSS styling & dark/light theme.
   - Student Portal UI: Dashboard, Room Allocation Application, Complaints Tracking UI.
   - Mess & Dining interactive schedule viewer, notices & real-time modal dialogues.
   - Student self-service tools, digital gate pass view, invoice downloads & mobile responsiveness.

3. BHOOMI PURUSHWANI (25% - Admin & Warden Operations Engineer):
   - Auth interfaces (Login & Register pages with role selection and form validation).
   - Admin Operations Hub: 11 functional management panels & room inventory visualizer.
   - Warden operations: Student directory, fee tracking console, attendance review desk.
   - Analytics dashboard, graphical reporting (Recharts/Chart.js), CSV/Excel report exports.

4. PALAK SARASWAT (25% - Operational Intelligence, Security & QA Engineer):
   - Attendance & Curfew Tracking System (Backend APIs + Warden marking desk + Student calendar).
   - Outstation Leave & Digital Gate Pass Workflow (Backend APIs + Multi-state approval + QR code pass).
   - Visitor & Security Gate Registry (Backend APIs + Security check-in/out desk + Overstay tracker).
   - Automated Postman Test Suite, Swagger/OpenAPI specifications, college documentation & viva prep.
